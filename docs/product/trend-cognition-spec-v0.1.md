# AI 趋势认知规格 v0.1

本文定义 DAO 中“理解趋势”的能力层级、最小认知循环和评测题型。它不规定模型或技术栈。

## 1. 能力分级

| 等级 | 名称 | 能力 | 典型失败 |
|---|---|---|---|
| L0 | 流畅叙事 | 能生成市场分析文字 | 内容合理但无法追溯或评分 |
| L1 | 有据观察 | 能区分事实、来源和时点 | 罗列事实但不形成状态 |
| L2 | 状态表征 | 能输出方向、生命周期、稳定性与不确定性 | 把分类当作未来预测 |
| L3 | 条件化推理 | 能形成竞争假设、情景概率、触发器和失效条件 | 情景不互斥，概率来自语言润色 |
| L4 | 信念修正 | 能根据新证据解释状态与概率为何变化 | 新旧观点矛盾但无变化记录 |
| L5 | 稳健迁移 | 能在不同市场环境中保持校准并识别分布外状态 | 只在熟悉行情或事后样本有效 |

DAO v0.1 的目标是：

- 稳定达到 L3。
- 对连续认知帧建立可审计的 L4。
- 暂不声称达到 L5。

## 2. 最小认知循环

### 2.1 Observe

输入为冻结的 point-in-time 证据包。输出只包含当时可验证的观察、质量和缺口。

### 2.2 Hypothesize

至少建立一个主假设和一个能够被未来数据区分的竞争假设。不同假设不能只是同一观点的语气变体。

### 2.3 Infer State

对方向、生命周期和稳定性形成后验分布。标签是信念状态，不是事实标签。

### 2.4 Project Conditionally

将未来表达为互斥情景，并为每个情景登记概率、触发条件、时间尺度和解析规则。

### 2.5 Challenge

主动寻找：

- 支持主假设的证据是否来自同一底层来源
- 能推翻当前状态的反方证据
- 数据陈旧、缺失或修订问题
- 更简单的朴素解释
- 分布外或事件跳跃风险

### 2.6 Gate

当证据质量、模型分歧或可解析性不达标时，降低信度或弃权。解释层不能取消守门结果。

### 2.7 Revise

新证据到来时生成 Cognition Delta。修正必须指向具体证据或模型版本变化，不能只写“市场发生变化”。

### 2.8 Resolve

到期后按预注册规则解析并评分，只追加结果，不改写旧帧。

## 3. 认知测试矩阵

| 测试 | 给模型什么 | 检查什么 | 主要指标 |
|---|---|---|---|
| T1 时间完整性 | 截止某时点的证据包 | 是否使用未来信息 | 前视违规数 |
| T2 证据落地 | 数据、事件和来源 | 结论是否逐项可追溯 | 证据覆盖率、无来源事实率 |
| T3 状态区分 | 多种趋势和区间片段 | 能否区分方向、阶段和稳定性 | 一致性、混淆矩阵 |
| T4 竞争假设 | 含冲突信号的样本 | 是否保留真正的反方解释 | 有效反方率、证据重复率 |
| T5 条件推演 | 当前状态与时间尺度 | 情景是否互斥、可解析 | Brier、log loss、完备性 |
| T6 失效敏感性 | 逐步加入关键新证据 | 是否在合理时点修正观点 | 修正延迟、虚警率 |
| T7 弃权 | 缺失、陈旧或分布外样本 | 是否拒绝伪精确判断 | 选择性风险、覆盖率 |
| T8 解释忠实 | 结构化帧与解释文本 | 文本是否篡改数字和条件 | 数值一致率、状态一致率 |

## 4. 金标准不是“事后正确答案”

市场状态具有不确定性，人工标注不能假装存在唯一真值。金标准应同时记录：

- 标注者当时可见的证据
- 标注者的状态分布而非只有单一标签
- 主假设与竞争假设
- 预期能够改变观点的新证据
- 分歧原因和是否允许多个合理答案
- 未来结果只用于解析预测，不反向修改当时认知

对于生命周期和稳定性，可使用双人独立标注加审议；对于方向情景，使用事先定义的可计算解析规则。

## 5. 错误分类

每个失败至少归入一种类型：

- `temporal_leakage`：使用了未来或修订后数据
- `unsupported_claim`：出现无证据事实
- `state_collapse`：把多维状态压成多空标签
- `duplicate_evidence`：重复来源被当成多份独立证据
- `scenario_overlap`：情景重叠或不完备
- `probability_incoherence`：概率不一致或不可解释
- `late_revision`：关键证据出现后未及时修正
- `overreaction`：对噪声频繁改变状态
- `failed_abstention`：证据不足时仍强行预测
- `explanation_drift`：解释篡改结构化结果
- `post_hoc_story`：用结果为旧判断补写理由

## 6. 模型与 Agent 的职责边界

| 环节 | 适合确定性程序或统计模型 | 适合 LLM / Agent |
|---|---|---|
| 数据时点和版本 | 校验、冻结、缺失检测 | 解释数据缺口的影响 |
| 特征与状态概率 | 计算、基线、校准 | 比较竞争解释 |
| 证据去重 | 来源图、相似度和规则 | 识别语义上的重复叙事 |
| 情景 | 概率约束和解析规则 | 生成可区分的候选情景 |
| 风险与弃权 | 硬阈值和守门规则 | 说明为何弃权 |
| 用户解释 | 数值一致性校验 | 生成忠实、克制的自然语言 |

不得以“多 Agent 一致”替代独立证据。多个 Agent 消费相同数据时，其意见不是多份独立观测。

## 7. v0.1 研究完成定义

只有满足以下条件，才能说 DAO 已建立“趋势认知原型”，而不只是生成分析文字：

- 存在覆盖主要状态和失败场景的 20—30 个 point-in-time 样本。
- 每个样本都有 Evidence、Market Cognition Frame、Cognition Delta 或明确的首帧标记。
- 所有概率问题都可解析并与朴素基线共同评分。
- 可以生成错误分类报告，而不只展示成功案例。
- 系统会在预设条件下弃权。
- 结构化结果与自然语言解释通过忠实性检查。
- 任何人可以从输入快照和版本重放同一研究过程。
