# 领域本体：形、势、机、时、位

这些名称来自中国传统思想，但在本项目中必须使用现代、可观测的定义。它们不是卦象，也不是固定买卖信号。

## 核心对象

| 概念 | 现代定义 | 典型问题 | 输出性质 |
|---|---|---|---|
| 形 | 已形成且可观察的市场结构 | 价格、波动与跨资产关系现在是什么样？ | 事实与状态估计 |
| 势 | 在当前结构与驱动力下继续演化的条件倾向 | 若条件不变，哪条路径更有优势？ | 条件概率，不是必然性 |
| 机 | 状态可能转换且值得提高观察频率的窗口 | 哪些触发器正在接近？ | 变化点风险 |
| 时 | 多个时间尺度及事件时钟所处环境 | 同一信号在当前周期意味着什么？ | 时间上下文 |
| 位 | 当前状态在趋势生命周期中的位置 | 形成、扩张、成熟、衰竭还是转换？ | 阶段分类 |

## 市场状态三轴

### 方向

- `up`
- `down`
- `range`
- `uncertain`

### 生命周期

- `formation`
- `expansion`
- `maturity`
- `exhaustion`
- `transition`

### 稳定性

- `stable`
- `fragile`
- `critical`

三轴组合比单一“多/空”标签保留更多决策信息。例如，`up + exhaustion + fragile` 与 `up + expansion + stable` 都是上涨，但参与方式和风险完全不同。

## 六维观变编码

在五个核心概念之外增加 `信`（evidence confidence），形成输出编码：

1. `形 / structure`：趋势、区间、波动和相关结构
2. `势 / propensity`：条件化方向倾向与持续性
3. `机 / transition_risk`：变化点概率与触发器距离
4. `时 / temporal_context`：时间尺度、事件窗口和周期
5. `位 / lifecycle`：趋势生命周期位置
6. `信 / evidence_confidence`：证据质量、独立性与新鲜度

## 约束

- “势”必须通过数据学习或规则明确计算，不能由 LLM 主观打分。
- “机”表示转折风险增加，不表示已经反转。
- “物极必反”只能启发脆弱性特征，不能构成逆势信号。
- 不同时间尺度分别建模，不把日线状态直接外推到分钟级。
- 任何分类都要保留后验概率、模型版本和输入快照。

## 与数据契约的关系

最终载体是 `Market Cognition Frame`，schema 位于 `schemas/market-cognition-frame.schema.json`。Agent 之间不传递自由文本结论，而传递带证据引用和时间戳的结构化字段；自由文本仅作为解释层。
