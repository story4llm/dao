# ADR-0002：以趋势认知为核心产品，而非交易信号或代码平台

- 状态：Accepted
- 日期：2026-07-29

## 背景

DAO 已完成研究报告与 Harness 初始化，但“AI 趋势认知系统”仍可能在实施中漂移为普通量化平台、多 Agent 演示项目或行情分析页面。

如果先讨论数据平台、技术栈和页面，系统很容易只是在更复杂地输出“看涨/看跌”；如果只依赖 LLM 生成合理叙事，又无法证明 AI 真正识别了状态、理解了变化或修正了观点。

## 决策

DAO 的首要研究对象是：

> 某一时点上，AI 基于当时可获得的信息形成的、可证伪且可修正的市场信念状态。

该状态以 `Market Cognition Frame` 为核心载体。系统必须能够：

1. 区分观察、推断、假设与决策。
2. 表达方向、生命周期、稳定性和后验概率，而非只给多空标签。
3. 解释主导力量、反方证据和证据冲突。
4. 给出互斥情景、条件、概率和可解析的失效标准。
5. 在新信息到来时说明“什么改变了、为何改变、改变多少”。
6. 在数据不足、冲突过大或分布外状态下弃权。

第一阶段的第一位用户是项目内部的趋势研究者。首要场景是 XAU/USD 日线与 4 小时级别的离线每日认知帧；事件驱动更新、外部交易者产品和盘中实时系统后置。

代码的职责限于获取和冻结数据、执行可复现计算、保存版本、回放、校验与评分。代码量、Agent 数量、页面数量和技术复杂度都不是阶段成功指标。

产品输出不得提供入场价、止损、止盈、仓位或自动下单。v0.1 的 `risk.allowed_actions` 仅表示内部研究姿态，不得作为交易动作展示；该字段已由 ADR-0003 和评估契约 v0.2 重命名为 `risk.research_posture`。

## 结果

正面：

- 项目会围绕“能否形成可靠认知”组织数据、模型、Agent 和评估。
- LLM 的语言能力与数值模型的概率计算保持分离。
- 每次观点变化可以被回放、解释和评分。
- 即使尚未选择技术栈，也能先建设高价值的金标准与评测资产。

代价：

- 第一阶段交付以认知契约、历史样本和评估报告为主，不追求产品外观。
- “理解”必须被拆成多个可测能力，无法用单一准确率证明。
- 每个历史样本都需要严格的 point-in-time 数据与人工审阅，制作成本较高。

## 被否决的方案

- 先建设完整行情平台和多 Agent 运行时：尚未证明认知任务本身有效。
- 以交易收益作为唯一指标：会混淆预测质量、风险偏好和执行结果。
- 用 LLM 分析报告作为最终产品：语言连贯不等于状态识别正确。
- 直接输出买卖点位：偏离认知目标，并引入不必要的合规和风险问题。
