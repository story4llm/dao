# ADR-0008：自动 Agent 运行模式

- 状态：accepted
- 日期：2026-07-31

## 决策

增加 `automated` 运行模式，作为本地 Agent 的默认执行模式。它的授权依据是调用者提供的 API key/账户环境，运行器不再要求人工复制快照或填写许可声明才能开始下载与分析。

`automated` 仍必须验证：凭据存在、HTTP 请求成功、来源响应可解析、合约身份、时间顺序、完整性、哈希、特征和基线可复现。许可信息只作为 provenance 元数据；缺失时写入 `licence_status: unknown`，不阻断运行。系统仍不执行交易。

`certified` 保留为需要完整研究审计证明的严格模式，但不再是 Agent 自动运行的默认路径。

## 理由

API key 已经是调用者对对应 API 权限的操作授权。将同一授权再次拆成手工路径和许可确认门，会把运行器变成表单审核器。数据质量和可复现性仍需要机器门，但许可后果由调用者承担。
