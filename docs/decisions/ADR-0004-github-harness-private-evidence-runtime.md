# ADR-0004：GitHub Harness 与私有运行证据分层

- 状态：Accepted
- 日期：2026-07-30

## 背景

DAO 的目标运行方式是让 AI 读取 GitHub 中的规则、状态和历史认知，再读取截止时点前的黄金证据，生成新的 Market Cognition Frame、Forecast Contract、Cognition Delta 和到期 Resolution Record。

但首选 XAU/USD 行情源属于许可受限市场数据。把完整原始序列、API token 或账户响应提交到公开 GitHub，会违反安全边界，并可能超出数据许可。另一方面，只让 AI 浏览公开图表又无法证明 bar 语义、首次可得时间和历史版本，不能支撑 Q1 回放。

## 决策

采用“公开/共享 Harness + 私有运行证据”的双层运行结构：

1. GitHub 是 AI 的长期规范、任务、状态和认知记录载体。
2. 许可受限原始行情保存在运行时私有目录或由用户在会话中临时附加。
3. GitHub 只保存去密钥请求清单、时间元数据、SHA-256、质量摘要和许可允许的派生研究记录。
4. 第一研究轨继续使用 provider-qualified `XAU_USD`；COMEX GC 保留为独立后续研究轨。
5. 首期价格源选择 OANDA REST v20 作为条件通过候选；是否进入 Q1 取决于账户地区、实际品种、协议接受和快照留存。
6. 政府宏观与事件数据优先直接使用原始机构页面或数据接口，不经许可不兼容的聚合服务。
7. 运行分为：
   - `certified`：核心价格与必要宏观证据通过资格门，可生成待评分预测。
   - `exploratory`：证据不完整时只形成 Q0 研究记录；核心价格不合格时必须预测弃权。

## AI 的职责

AI 是趋势认知与竞争假设的推理主体，不只是报告润色器。它可以：

- 选择和解释相互竞争的趋势假设。
- 根据冻结的证据与已声明的基线形成版本化概率预测。
- 比较相邻认知帧并解释信念变化。

AI 不可以：

- 猜测缺失行情或发布时间。
- 把网页摘要当作合格原始序列。
- 在没有冻结基线、证据包或概率流程时填写看似精确的概率。
- 修改程序已计算的 ATR、基线或到期结果。

## 后果

### 正面

- GitHub Harness 可以被 ChatGPT、Codex、Claude Code 等不同 AI 稳定读取。
- 市场数据许可和凭据不会被仓库泄露。
- 认知帧仍可通过清单与哈希追溯到当次私有输入。
- 没有合格数据时，系统会阻断预测而不是生成虚构结论。

### 代价

- “只读 GitHub”不足以完成 certified 预测；每次运行还需私有证据包。
- 公开仓库无法独立复现许可受限的原始价格序列。
- 首次真实运行需要用户准备 OANDA 或等价合格来源的账户级快照。

## 被拒绝的方案

- **把 OANDA/经纪商完整行情提交到 GitHub**：违反最小安全边界，且可能超出内部使用许可。
- **只用公开网页和截图**：无法满足 point-in-time 与 bar 语义硬门。
- **立即切换到 GC 连续合约**：引入付费许可、具体合约与换月问题，不能更快建立首个 XAU/USD 认知闭环。
- **使用 FRED/ALFRED 作为 AI 运行数据源**：当前条款与本项目 AI 使用方式不兼容。
