# 定义趋势认知 PRD v0.1

## 问题

项目已经明确以 AI 对趋势的理解为重心，但尚未定义“理解”的可观察能力、第一位用户、最小使用流程和研究完成标准，容易提前漂移到代码平台或交易信号。

## 范围

- 固化“认知优先”的产品决策。
- 定义第一位用户与每日离线认知场景。
- 定义 Market Cognition Frame 在产品闭环中的位置。
- 建立趋势认知 L0—L5 能力分级。
- 定义首批 20—30 个金标准样本的评测方向。
- 更新项目状态、开放问题和上下文入口。

## 非目标

- 不实现行情数据接入、模型、Agent 运行时或前端。
- 不修改 Market Cognition Frame schema。
- 不定义买卖、点位、止损、止盈或仓位。
- 不在小样本上声称预测优势。

## 必要上下文

- `AGENTS.md`
- `docs/product/vision.md`
- `docs/architecture/domain-ontology.md`
- `evals/README.md`
- `state/PROJECT_STATE.md`
- `state/OPEN_QUESTIONS.md`

## 输入与输出契约

- 输入：现有研究报告、领域本体、三类 schema 与项目开放问题。
- 输出：ADR-0002、PRD v0.1、趋势认知规格 v0.1、更新后的项目状态。
- `as_of` / `data_cutoff`：本任务不生成市场判断，不适用。

- [x] 明确代码、LLM、统计模型和人工标注的职责边界。
- [x] 下一里程碑聚焦金标准样本，不启动平台代码。
- [x] 仓库自动校验通过。

## 验证

- 自动：`make validate`
- 人工：检查文档是否把重点放在信念状态、条件推演、修正与弃权，而非买卖信号。
- 基线或反方检查：确认没有用多 Agent 数量、代码复杂度或短期盈亏替代认知质量。

## 结果

已形成 PRD v0.1 与趋势认知规格，项目从 Harness Bootstrap 推进到认知评测设计。下一单一主题任务是制定金标准标注指南并完成首批样本。

## 决策与风险

- 决策：第一位用户为内部趋势研究者；首要场景为 XAU/USD 日线/4 小时的每日离线认知帧。
- 残余风险：状态标签、情景解析规则、数据许可和 Cognition Delta schema 仍未定稿。
- 后续任务：金标准标注指南与首批 5 个试标样本。
