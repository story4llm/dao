# 金标准趋势认知标注指南 v0.1

- 状态：Pilot draft
- 日期：2026-07-30
- 适用标的：XAU/USD
- 观察尺度：日线为主，4 小时辅助
- 首要推演尺度：未来 3—5 个交易日

## 1. 金标准的定义

DAO 的金标准不是“事后最正确的趋势名称”，而是：

> 在已冻结的 `data_cutoff` 下，标注者仅使用当时可获得的证据，形成一份可追溯、可证伪、带不确定性且允许弃权的专家信念记录。

金标准约束认知过程，不把不确定市场伪装成唯一真值。未来数据只用于解析预先登记的情景，不得反向修改原认知帧。

## 2. 认证等级

| 等级 | 名称 | 必须满足 | 可用于 |
|---|---|---|---|
| Q0 | 协议试标 | 样本、标签理由和已知缺口完整 | 暴露协议与 schema 问题 |
| Q1 | 时点单标 | point-in-time 来源、版本、时区和 `available_at` 已验证；单人盲标 | 标注训练与流程演练 |
| Q2 | 审议金标 | 两人独立盲标、分歧量化、审议记录完整 | 模型评测参考答案 |
| Q3 | 已解析金标 | Q2 + 预测到期 + 按预注册规则解析与评分 | 概率校准和基线比较 |

Q0 不得写成 gold-standard。Q1 不能替代双人一致性。Q2 不能在结果窗口打开后改写。Q3 的解析记录只能追加。

## 3. 样本单元

每个样本由四个物理分离的对象组成：

1. `selection_manifest`：为什么选择这个时点、选择偏差和目标覆盖类别。
2. `evidence_snapshot`：截止 `data_cutoff` 已可获得的证据。
3. `annotation_record`：独立标注、分歧和审议结果。
4. `resolution_record`：未来窗口结束后追加的结果和评分。

盲标时只向标注者开放 2 和空白的 3。选择者不能向标注者泄露目标类别。`resolution_record` 在认知帧冻结前不得创建或展示。

## 4. 时间协议

### 4.1 四个时间

- `observed_at`：市场或事件实际发生时间。
- `available_at`：信息首次可被研究者获得的时间。
- `recorded_at`：进入证据快照的时间。
- `data_cutoff`：本次认知允许使用信息的最晚时间。

只有 `available_at <= data_cutoff` 的证据可以进入认知帧。宏观数据使用首次发布值或明确的 vintage；最终修订值不能用于历史盲标。

### 4.2 固定截止规则

- 常规样本：使用预先选定的每日 UTC 截止时点。
- 事件样本：截止时点必须早于事件发布，且不得包含跨越事件的 4 小时 K 线。
- K 线必须声明时间戳表示开盘还是收盘，并声明时区。
- 无法证明时区、发布时间或历史版本时，最高只能认证为 Q0。

## 5. 证据包

最小证据包应覆盖：

- XAU/USD 日线结构：至少 60 个交易日。
- XAU/USD 4 小时结构：至少 30 个完整 bar。
- 美元、实际利率：与价格使用一致的截止时点。
- 已知事件时钟：未来 5 个交易日内的高影响计划事件。
- 数据质量：缺失、陈旧、修订、时区和许可。

每项证据必须包含来源、观察时点、可获得时点、质量和依赖组。多个指标由同一价格序列派生时，只算一个独立来源。

评估契约 v0.2 已将 `dependency_group`、`source_timezone`、`bar_timestamp_semantics`、`availability_verified`、`licence` 和 `vintage_id` 结构化。Q0 允许这些字段为 `unknown`、`false` 或 `not-captured`；Q1/Q2 必须提供可审计证明，不能只填字段。

## 6. 标签操作定义

### 6.1 方向

方向是当前结构的后验信念，不是未来结果。

| 标签 | 操作锚点 |
|---|---|
| `up` | 日线正向位移明显，结构高低点或持久性支持向上，且反方不足以使区间成为主解释 |
| `down` | 日线负向位移明显，结构高低点或持久性支持向下，且反方不足以使区间成为主解释 |
| `range` | 净位移相对路径长度较小、反复回到价值区，突破尚未获得保持确认 |
| `uncertain` | 关键数据不足，或前三种解释不能形成可审议的主导项 |

`state.posterior.up + down + range` 必须等于 1。`direction=uncertain` 时仍保留三项分布；任一项不得因语言直觉超过 0.85。

### 6.2 生命周期

| 标签 | 操作锚点 | 常见误判 |
|---|---|---|
| `formation` | 新方向刚出现，旧结构开始失效，但持续时间或跨尺度确认不足 | 把单根大 K 线当新趋势 |
| `expansion` | 方向位移、路径效率与跨尺度结构共同延续，回撤尚未破坏主结构 | 只因创新高就叫扩张 |
| `maturity` | 方向仍保持，但加速度或证据一致性减弱，进入持续与衰减之间 | 把“成熟”直接解释为反转 |
| `exhaustion` | 原方向尚未反转，但延伸、波动、拒绝或驱动背离使脆弱性显著上升 | 用“物极必反”直接做空 |
| `transition` | 旧状态已有关键破坏，新状态尚未稳定或不同尺度冲突 | 事后把转换点精确到最低/最高点 |

对于 `direction=range`，v0.1 暂只组合：

- `range + formation`：新平衡正在形成。
- `range + maturity`：平衡已持续。
- `range + transition`：正在离开平衡。

这条规则用于避免把趋势生命周期机械套到区间上。

### 6.3 稳定性

| 标签 | 操作锚点 |
|---|---|
| `stable` | 主状态由至少两个相对独立的观察支持，关键失效条件距离较远，近期无未建模事件跳跃 |
| `fragile` | 主状态仍占优，但存在驱动背离、结构拒绝或接近的失效条件 |
| `critical` | 旧结构已破坏、证据强冲突、关键事件临近，或数据质量足以改变结论 |

稳定性描述状态的抗扰动能力，不等同于预测置信度。

## 7. 概率与“势、机、信”

- 概率以 0.05 为最小步长，避免伪精确。
- 标注者先独立写概率，再写解释，不能先写叙事后补数字。
- `势 / shi` 表示若已列条件保持时的方向倾向，范围为 `[-1, 1]`；Q0/Q1 可作专家锚定值，进入模型评测前必须由规则或模型产生。
- `机 / ji` 表示未来 3—5 日发生状态迁移的风险，范围为 `[0, 1]`，不代表反转方向。
- `信 / xin` 表示证据质量、独立性和新鲜度，不是上涨概率。
- 同一底层价格序列派生的收益、均线、效率比和波动率必须视为相关证据，不能重复提高 `xin`。

## 8. 弃权

满足任一硬条件时必须 `abstain=true`：

- 无法证明关键输入在 `data_cutoff` 前可获得。
- 日线或 4 小时关键窗口缺失，且缺失足以改变状态。
- 预测窗口内存在未建模的离散事件，且没有校准的事件条件模型。
- 证据分歧超过审议阈值，无法形成可区分情景。
- 情景不能互斥、不能解析或概率无法由约束过程给出。
- 样本处于已定义训练分布之外。

弃权不是删除认知。仍应输出当前状态分布、数据缺口、重新评估条件和研究姿态。均匀概率不能替代弃权理由。

## 9. 独立标注与分歧处理

两位标注者使用相同证据包，独立完成：

1. 时间完整性检查。
2. 主假设与竞争假设。
3. 方向分布、生命周期、稳定性。
4. 支持与反方证据。
5. 情景概率、触发器与失效条件。
6. 是否弃权及原因。

进入审议的阈值：

- 方向最大后验标签不同。
- 任一方向概率差绝对值大于 0.20。
- 生命周期相差两个以上相邻阶段。
- 稳定性不同。
- 一人弃权、一人不弃权。
- 两人引用的关键证据依赖组重叠率低于 0.50。

审议不能简单取平均。必须记录分歧来自证据遗漏、定义歧义、时间问题还是合理多解。若无法消除，保留分歧并弃权。

## 10. 双阶段盲标流程

### 阶段 A：选择与冻结

1. 样本选择者按覆盖矩阵选时点，并记录是否使用未来数据帮助选择。
2. 数据管理员冻结证据快照、来源版本和校验值。
3. 时间审计员删除所有 `available_at > data_cutoff` 的材料。
4. 未来窗口材料存入不可见区域。

### 阶段 B：独立认知

1. 标注者先检查数据质量，不先看价格图标题或目标类别。
2. 分别填写主假设、竞争假设和概率。
3. 运行概率和、引用和确定性措辞检查。
4. 冻结两个独立记录。

### 阶段 C：审议

1. 自动生成字段差异。
2. 只讨论超过阈值的分歧。
3. 记录修改原因；不得引用未来结果。
4. 形成 Q2 认知帧或明确弃权。

### 阶段 D：解析

1. 到 `horizon.ends_at` 后才开放未来数据。
2. 按预注册 resolution rule 解析。
3. 追加 Brier、log loss、基线和错误分类。
4. 原始 Q2 帧保持不可变。

## 11. 防止后见偏差

- 样本选择者与标注者分离。
- 目标类别只写在选择清单，不写入盲标输入。
- 不使用事后综述、季度回顾或后来修订的数据作为认知证据。
- 样本选择若依赖未来走势，必须标记 `retrospective_target_sampling`，且不得用于性能统计。
- 文件名在盲标阶段使用随机 ID，不包含 `expansion`、`exhaustion` 等答案。
- 任何基于未来结果新增的解释归类为 `post_hoc_story`。

## 12. Q2 接受清单

- [ ] 来源、许可、时区、版本和首次可得时间可证明。
- [ ] `data_cutoff` 后的证据为零。
- [ ] 两名标注者独立完成，未看未来窗口。
- [ ] 状态三轴、后验、情景和失效条件完整。
- [ ] 支持与反方证据均可定位，依赖来源已去重。
- [ ] 概率和为 1，情景互斥且可解析。
- [ ] 分歧和审议理由完整。
- [ ] 弃权硬条件已经执行。
- [ ] 未来解析规则在看结果前冻结。
- [ ] 认知帧和解释没有买卖、点位或收益承诺。

## 13. 本轮试标结论

首批五个样本用于测试协议，不用于性能评估。它们全部暂定为 Q0，主要原因是公共 XAU/USD 数据集的 4 小时时区、bar 语义、历史首次可得时间和许可尚未达到 Q2 证明标准。

试标暴露的四项契约缺口已由[评估契约 v0.2](evaluation-contract-v0.2.md)处理：

1. Evidence schema 已增加依赖组、时区、bar 语义、许可、vintage 和可得时间验证字段。
2. Market Cognition Frame 已使用 `risk.research_posture`，并拆分状态弃权与预测弃权。
3. `direction=range` 时生命周期的合法组合已由 schema 约束。
4. Cognition Delta、Annotation Record 与 Resolution Record 已拥有独立 schema。

结构迁移不改变认证等级：五个样本继续保持 Q0，仍不得用于性能统计。
