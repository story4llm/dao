# 五类试标发现

## 1. 结论

五个样本足以证明“标签名称”还不是金标准。真正决定样本是否可用的是时间证据、依赖去重、分歧协议和解析规则。

本轮没有把任何样本升级为 Q1。阻止升级的原因不是标签难写，而是数据来源缺少可证明的 4 小时时区、bar 语义、历史首次可得时间和许可。

## 2. 各样本暴露的问题

### `pilot-a17`

20 日价格位移与路径效率支持上涨扩张，但实际利率最近五个观测回升。初步结果表明：

- “扩张”不要求所有驱动同向。
- 宏观反向证据应降低稳定性或信度，不能覆盖已经形成的价格结构。
- 多个价格派生指标必须归入同一依赖组。

### `pilot-b04`

价格仍处在上行结构，同时出现较大日内拒绝、波动扩张和美元/实际利率反向。初步结果表明：

- `exhaustion` 描述脆弱的原趋势，不等于 `down`。
- 只有未来发生结构破坏，才能在新帧中标记 `transition`。
- “物极必反”不能代替可观察的失效条件。

### `pilot-c22`

20 日净位移接近零，但短期位移和 4 小时效率显著上升。初步结果表明：

- `range + maturity` 可以与“正在尝试突破”同时成立。
- 需要用保持确认而不是单根突破判定离开区间。
- v0.1 schema 无法约束 range 合法生命周期组合；v0.2 已加入条件约束。

### `pilot-d09`

价格、美元和实际利率在事件前仍可形成倾向，但一小时后存在未建模 FOMC 决议，且 4 小时数据的 bar 边界无法被严格证明。初步结果表明：

- 状态表征和未来方向预测必须分开；系统可以描述当前状态，同时对情景概率弃权。
- 临近事件不是自动弃权条件；“无校准事件模型 + 时间边界不可靠”才构成本例硬门。
- v0.1 MCF 只有一个 `abstain`；v0.2 已拆分状态弃权与预测弃权，本样本只对预测弃权。

### `pilot-e31`

日线 20 日仍为正，但最近 5 日和 4 小时结构快速转负，美元与实际利率同步走强。初步结果表明：

- `transition` 能保留“旧上涨已受损、新下跌尚未稳定”。
- 单日结构破坏不应直接标记 `down + expansion`。
- Cognition Delta 必须解释后验如何从旧状态迁移，单帧不足以评价 L4 能力。

## 3. 契约修订状态

评估契约 v0.2 已完成：

1. Evidence Item 已增加：
   - `dependency_group`
   - `source_timezone`
   - `bar_timestamp_semantics`
   - `availability_verified`
   - `licence`
   - `vintage_id`
2. Market Cognition Frame 已：
   - 将 `risk.allowed_actions` 改为 `risk.research_posture`。
   - 区分状态弃权与预测弃权。
   - 对 range 与生命周期组合增加条件约束。
3. 已新建：
   - Cognition Delta schema
   - Annotation Record schema
   - Resolution Record schema

4. 已预注册 `xauusd-direction-5d:0.2.0`：第 5 个完整交易日正式评分，第 3 日只作诊断。

## 4. 下一轮建议

下一任务仍不应直接扩展到 20—30 个样本：

1. 建立数据源资格矩阵。
2. 找到至少一个具有明确时区、许可和历史可得时间的 XAU/USD/GC 数据源。
3. 用同五个时点重新制作 Q1。
4. 安排双人独立标注和 Q2 审议。
5. 等未来窗口按预注册规则解析后，再建立 Q3。
